# The Art of Code

*A collection of ideas, code and creativity.*

## About

The Art of Code is my personal portfolio, inspired by the
concept of a contemporary art museum.

A space where creativity, design and development come
together to showcase my work, skills and projects.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design
- Light and dark themes
- Interactive project gallery
- Individual project showcases
- Contact section

## Project Structure

- `assets/` - Images, icons and fonts.
- `css/` - Stylesheets.
- `js/` - JavaScript functionality.
- `projects/` - Individual project pages.
- `index.html` - Main portfolio page.
